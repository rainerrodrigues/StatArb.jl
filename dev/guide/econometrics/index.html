Cointegration diagnostics

Engle-Granger

engle_granger! works in two steps:

  1. it regresses y = α + β x + ε by OLS;
  2. it runs an ADF test on the residuals, with no deterministic terms, and compares the statistic with the MacKinnon (2010) response-surface critical values for two variables (mackinnon_crit).

During formation, test_pairs runs it in both orientations and keeps the more negative statistic.

The ADF regression is Δx_t = [c] + γ x_{t−1} + Σ φ_i Δx_{t−i} + u_t. adf! uses a fixed lag order and adf_auto! picks the order by AIC over a common sample.

Johansen

For a k × W window, johansen! estimates the VECM

\[\Delta X_t = \alpha(\beta' X_{t-1} + \rho_0) + \sum_{i=1}^{p-1} \Gamma_i \Delta X_{t-i} + \varepsilon_t\]

It then solves the generalized symmetric eigenproblem $S_{10} S_{00}^{-1} S_{01} v = \lambda S_{11} v$ with LAPACK dsygvd, the routine behind LAPACK.sygvd!. The call goes through ccall with buffers owned by the workspace, because the high-level wrapper allocates them on every call. From the eigenvalues it computes

\[\lambda_{\text{trace}}(r) = -T \sum_{i=r+1}^{k} \ln(1-\lambda_i), \qquad \lambda_{\max}(r, r+1) = -T \ln(1-\lambda_{r+1})\]

The rank comes from the sequential trace test. The workspace also holds the leading cointegrating vector (normalised so its first entry is 1) and the half-life of the implied spread.

All second moments come from a single BLAS.syrk! on the stacked data matrix. The short-run dynamics are concentrated out with in-place Cholesky solves, so no residual matrices are ever formed.

Deterministic terms

detModelCritical values
:restricted (default)constant inside the cointegrating relation, no drift in pricesOsterwald-Lenum (1992), Table 1*
:unrestricteddata demeaned, so prices may trendMacKinnon-Haug-Michelis (1999), case 3

A price spread has a mean but no trend, so :restricted is the right null for pairs. On drift-free random walks the unrestricted tables reject 12–31% of the time at a nominal 5%.

Half-life

ou_half_life fits Δs_t = a + b s_{t−1} and returns −ln 2 / ln(1 + b). If the spread doesn't mean-revert (1 + b ∉ (0, 1)), it returns Inf.

The health gate

Every health_every bars, each live pair is re-tested on its rolling window. If the Johansen rank drops to 0, or the half-life leaves hl_bounds, the pair moves to QUARANTINE: it can close positions but not open new ones. It returns to ACTIVE after recover_checks passing checks in a row. Setting gate_on = :eg gates on Engle-Granger instead, and :either keeps a pair active while at least one of the two tests passes. See HealthGateConfig.

Window length and power

Short windows lack the power to detect slowly reverting spreads. With a half-life of 10 bars, a 120-bar window often fails to reject even when the pair really is cointegrated, so healthy pairs keep getting quarantined. The default health_window = 250, and the sensitivity sweep shows what shorter windows cost.

Pre-screening

Testing every pair takes $N(N-1)/2$ tests. distance_screen first z-normalises log prices over the formation window and keeps the screen_top pairs with the smallest sum of squared differences, optionally only within a sector.
