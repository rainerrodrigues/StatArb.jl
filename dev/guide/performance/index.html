How the kernels avoid allocating

  • Workspaces: OLSWorkspace, EGWorkspace and JohansenWorkspace own every buffer they need. Create one per thread and reuse it.
  • Small dense algebra: Cholesky factorisation and triangular solves on matrices of dimension ≤ ~20 use hand-written loops, which avoids LAPACK's call overhead and the heap allocations of the high-level wrappers.
  • LAPACK directly: the Johansen eigenproblem calls dsygvd through ccall, with WORK and IWORK buffers owned by the workspace.
  • Static arrays: the Kalman state lives in SVector/SMatrix fields, so updates stay in registers.
  • Contiguous windows: mirrored ring buffers hand out contiguous views, so the rolling statistics read memory in order.

The test suite asserts @allocated == 0 for every kernel, measured inside a function. At the top level of a test block, Julia also counts the boxing of captured variables. CI runs JET over the whole package, so a type instability or a possible MethodError fails the build.

Threading tips

  • Start Julia with -t auto.
  • Formation scans and sweeps pin BLAS to one thread while they run.
  • sensitivity_sweep runs one backtest per task. It turns off threading inside formation, so the two levels of parallelism don't oversubscribe the cores.
