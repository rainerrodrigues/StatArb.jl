API

Data

StatArb.Clock — Type
Clock(t)

Single monotonic clock for a simulation. The clock only moves forward (tick!), and all data access for signal generation goes through history/assert_past, which throw a LookaheadError for any index beyond clock.t.

source
StatArb.CorporateAction — Type
CorporateAction(asset, t; split=1.0, dividend=0.0)

A corporate action on bar t (the ex-date) for asset:

  • split: shares received per share held (2.0 for a 2-for-1 split, 0.1 for a 1-for-10 reverse split)
  • dividend: cash paid per pre-split share

Panel mid prices are raw (as traded), so they drop on the ex-date. The backtester multiplies share positions by split, credits longs / debits shorts the dividend, and rescales resting orders. Signals use logmid, which is adjusted forward in time only (see PricePanel), so the adjustment never leaks future information.

source
StatArb.LookaheadError — Type
LookaheadError(requested, now)

Thrown when code asks for bar requested while the simulation clock is at bar now.

source
StatArb.MirroredRing — Type
MirroredRing(k, W)

Fixed-capacity circular buffer of k-vectors with lookback W. Every sample is written twice (positions p and p+W of a k × 2W matrix), so the most recent W samples are always one contiguous, chronologically ordered block: window(r) returns a plain SubArray with no copying, wrap-around logic or allocation.

source
StatArb.PricePanel — Type
PricePanel

Synchronised multi-asset bar panel. Every field matrix is n_assets × n_timestamps and stored column-major, so one bar (all assets at time t) is a contiguous column.

Fields

  • symbols, timestamps (strictly increasing), sector (integer group labels)
  • mid: raw mid prices, as traded (used for fills, valuation and financing)
  • logmid: log prices adjusted for corporate actions causally: on and after an ex-date the log of the cumulative adjustment factor is added, so the series is continuous through splits and dividends but never depends on future actions. All statistics and signals use logmid.
  • spread: absolute quoted spread (ask − bid)
  • volume: bar traded volume in shares (drives participation caps and impact)
  • depth: displayed size at the touch in shares (liquidity verification)
  • tradable: false where the bar was missing in the source data, had zero volume, or was marked halted; no fills happen there and no new positions are opened
  • actions: corporate actions sorted by bar
  • bars_per_year: annualisation constant (252 for daily bars)
source
StatArb.PricePanel — Method
PricePanel(mid; symbols, timestamps, spread, spread_bps=5, volume, default_volume=1e6,
           depth, depth_frac=0.01, sector, bars_per_year=252,
           missing_policy=:error, tradable=nothing, actions=CorporateAction[])

Build a validated panel from an n_assets × T mid-price matrix. Missing microstructure fields are filled with conservative defaults (a constant relative spread, constant volume, depth equal to depth_frac of bar volume).

Missing prices (missing, NaN, non-positive values):

  • missing_policy = :error (default) rejects the panel;
  • missing_policy = :ffill carries the last valid price forward (a leading gap takes the first valid price) and marks those bars non-tradable with zero volume and depth.

tradable is an optional n_assets × T Bool mask of additional halts. Bars with zero volume are always non-tradable.

Kalman filter

StatArb.KalmanConfig — Type
KalmanConfig(; model=:ou, delta=1e-4, q_scale=1.0, r_scale=1.0, obs_noise_frac=nothing, recalibrate=true)

Which state-space model to run and how to calibrate it from the formation window.

model = :rw: state [α, β] follows a random walk and the spread is treated as observation noise (KalmanHedge). R = r_scale · σ²_ols and

Q = q_scale · δ/(1−δ) · σ²_ols · diag(1, 1/x̄²)

(Chan's δ made unit-free). The trading signal is the innovation Z-score e/√S.

model = :ou: state [α, β, s] where the spread s is an AR(1)/Ornstein-Uhlenbeck process (OUKalmanHedge). φ, the spread shock variance σ²_η and the measurement noise R are estimated from the OLS residuals by ou_noise_fit (AR(1)-plus-noise moments). Setting obs_noise_frac to a number fixes R = obs_noise_frac · σ²_s instead. R is then multiplied by r_scale. The α, β noise uses the same δ scheme relative to σ²_s. The trading signal is the filtered spread ŝ_{t|t} / σ_s. With recalibrate = true, every health check re-fits φ and σ²_η on the rolling window.

q_scale and r_scale exist for misspecification stress tests.

source
StatArb.KalmanHedge — Type
KalmanHedge

Filter state for one pair. After kalman_update! the fields e (innovation), S (innovation variance F P_{t|t-1} F' + R) and z = e/√S (the uncertainty-aware trading Z-score) describe bar t using only information up to t.

source
StatArb.OUKalmanHedge — Type
OUKalmanHedge

Three-state filter θ_t = [α_t, β_t, s_t]:

y_t = α_t + β_t x_t + s_t + ϵ_t,          ϵ_t ~ N(0, R)
α_t = α_{t-1} + ω_α,   β_t = β_{t-1} + ω_β,   s_t = φ s_{t-1} + η_t,   η_t ~ N(0, σ²_η)

Modelling the spread as an AR(1) state instead of observation noise removes the autocorrelation the random-walk model leaves in its innovations. The trading signal z = ŝ_{t|t} / σ_s is the filtered spread in units of its stationary standard deviation σ_s = σ_η / √(1 − φ²); innovation_z holds the standardised prediction error. All updates run on StaticArrays with zero allocations.

StatArb.ou_noise_fit — Method
ou_noise_fit(e) -> (φ, σ²_η, R)

Fit "AR(1) spread + white measurement noise", e_t = s_t + ϵ_t, by matching the first three autocovariances: φ = γ₂/γ₁, σ²_s = γ₁/φ, R = γ₀ − σ²_s, σ²_η = σ²_s (1 − φ²). When the moments are not informative (γ₁ ≤ 0 or φ ∉ (0, 1)), falls back to a plain AR(1) fit with no measurement noise. R is floored at a small fraction of σ²_s. Allocation-free.

source

StatArb.RiskConfig — Type
RiskConfig(; ...)
  • pair_cap: gross dollars per pair as a fraction of equity (equal-dollar-style legs, split 1 : |β| between the y and x legs)
  • max_gross: portfolio gross exposure cap (multiple of equity)
  • throttle_uncertainty: scale size by the Kalman posterior throttle min(1, P_ref/P_ββ)
  • correlation_overlay: mean-variance weights across open spreads, w ∝ Σ⁻¹ μ with μᵢ = signalᵢ · κᵢ (κ = ln2 / half-life). Correlated, slowly reverting spreads end up with small or even opposite weights, i.e. they act mainly as hedges for faster spreads.
  • cov_window: bars of spread returns for Σ; shrinkage toward the diagonal
  • min_trade_frac: rebalance hysteresis (fraction of the pair cap)
  • maintenance_margin: minimum equity / gross exposure. Below it (or at non-positive equity) every position is closed at market and new entries are blocked for liquidation_cooldown bars (permanently if equity is gone)

StatArb.sensitivity_sweep — Function
sensitivity_sweep(panel, base=BacktestConfig(); q_scales, r_scales, windows, hl_scales,
                  threaded=true) -> Vector{NamedTuple}

One-at-a-time perturbation sweep around base:

  • q_scales multiply the Kalman state-noise Q
  • r_scales multiply the observation noise R
  • windows rolling health-check lookbacks W (the half-life upper bound is lowered to just under W/2 where needed, since longer half-lives can't be estimated on W bars)
  • hl_scales multiply every estimated half-life used for time stops and the overlay's reversion speeds (< 1 ⇒ over-estimating reversion speed)

Each run is an independent backtest, so runs are executed in parallel threads (formation threading is disabled inside to avoid nested oversubscription).
